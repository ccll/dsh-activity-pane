# C-090 移动端「活动」开关落位收敛为标题行行首（左边栏切换按钮右侧）

日期: 2026-10-10

#### 上下文
T-162 将开关嵌入视图导航行（对话/轨迹/上下文）行尾后，东家实测反馈「嵌到行尾体验不好」，指示改插入到左边栏弹出按钮的右侧、把其它按钮往后挤。

#### 决策
落位目标收敛为头部标题行行首（视觉上位于左边栏切换按钮右侧），其余头部控件被真实后挤；徽标单挂与显式钉宽形态维持 T-161/T-162 沉淀。

#### 被否方案及原因
- 维持导航行行尾：东家实测后否决，徽标远离视觉锚点（侧栏按钮）。
- 回退浮层：遮挡问题回归 T-160 之前。

#### 影响面
R-01-008 / 窗格渲染器（T-163）
