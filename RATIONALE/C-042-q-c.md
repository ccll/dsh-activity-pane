# C-042 待回复卡 Q 行列表的编号与省略口径（补充 C-041）

日期: 2026-08-27

#### 上下文
C-041 落地后复审（T-079 code-review）指出两个边界口径未在决策层明确：Qn 编号当中间问题不可得时如何延续；「最多 3 条」省略行在何种边界出现。实现已按既定行为落定，此处仅将口径写入决策记录，避免用户可见契约悬空。

#### 决策
- 每条编号按问题在 `questions` 数组中的原始位置（1 基）：中间不可得的问题跳过、不占号，后续编号不重排（可出现 Q1→Q3 跳号），与原生提问对话框的序号一致。
- 省略行「…」仅当可展示条数超过 3 时出现；恰 3 条或不足 3 条不出现省略行（不可展示的问题不占用展示名额）。
- 单条前缀「Q：」按原始条数判定：`questions` 只有一条时使用，与展示条数无关。

#### 被否方案及原因
- 编号按展示序列连续重排（1、2、3…）：会与对话中用户看到的原生问题序号错位，跨界面核对问题归属时产生歧义。
- 省略行按原始条数判定（如 5 条原始问题即加省略行）：当多条问题不可得时省略行与展示内容脱节（展示不足 3 行却显示省略），信息失真。
