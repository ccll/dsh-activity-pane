# T-156 活文档写作风格告警清零

状态: completed
关联: 全部 R-gg-nnn 的措辞层收敛（无 R/AC 语义变化、无 AC 增删）
风险等级: standard

## 背景与目标

- 背景: agentmap-bootstrap 将 AGENTS.md 与 agentmap_lint.py 升级到当前 canonical 版本后，新写作风格检查报出 222 条 warning。
  - 分布：PRD 53、SOLUTION 110、DOMAIN 25、RATIONALE 26、TODO 3、CONVENTIONS 5。
  - 东家指示修所有 warning。
- 目标: 五个活文档（PRD/SOLUTION/DOMAIN/TODO/CONVENTIONS）风格告警清零。
  - RATIONALE 只追加、不可改写，其 26 条告警作为结构性永久债务保留并向东家报告。

## 差距评估

- 现状：告警三类。
  - 多规则列表项：内容超 160 字符或含 3 个以上 `。` `；` 停顿。
  - 长名词堆叠：14 连续以上无断链 CJK 字符。
  - 含糊词：`尽快`、`尽量`。
- 目标：每条列表项一规则、无 14 连续以上名词串、无含糊词；全部改动语义零变化。

## 收敛方案

1. PRD：53 条告警清零。
   - 多规则 AC 拆为父项加子项，EARS 主句留在父行。
   - 名词串以逗号或「的/是/而/在」断链。
   - `尽快` 与 `尽量` 两词按仓库既有锚点删除：紧迫度由金色卡面与同频同相脉冲承载，颜色分散的量化下限由 R-01-003/AC-12 承载。
2. SOLUTION：110 条告警清零。
   - 同样拆分与断链。
   - 删除与原 287 行逐字节重复的 289 行。
   - `催促尽快响应` 改为 `催促用户及时响应`：仓库无可判定时限锚点，待东家复核，如需时限须走 PRD 演进。
3. DOMAIN：25 条告警清零。
   - 同样拆分与断链。
   - 阻塞等待定义中的 `尽快` 删除，同一待复核项。
4. TODO：3 条、CONVENTIONS：5 条告警清零。
   - 均在 canonical commit block 之外拆分，规则逐字保留。
