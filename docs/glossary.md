# 术语表

## 术语

- **会话**: 宿主中一次可寻址的 agent 工作单位，具有稳定 id、显示标题与状态。
- **主会话**: 没有父级会话归属的会话。
- **母会话**: 直接拥有一个或多个子代理的会话，可以是主会话，也可以是更深层子代理。
- **子代理**: 作为另一会话直属子级运行的会话，结束后即离开活动视图。
- **工作区**: 会话所属的工作目录分组，窗格以名称徽标展示，未归入任何工作区的会话没有徽标。
- **工作区名胶囊**: 名称徽标在紧凑档标题行内的无图标内嵌形态，完整与中间呈现的归属标识由独立徽标行承担。
- **工作区颜色槽位**: 由工作区身份（路径优先、名称兜底）确定性派生的稳定前景与背景复合颜色槽位——前景侧为 12 个避红 OKLCH 感知槽位、每个槽位提供 3 个同色相族背景变体，供同一工作区的全部徽标统一着色且不依赖其它工作区或存储。
- **层级连接线**: 活动区中位于母会话与子代理卡片或后台任务卡片缩进槽内、用于表达直属层级关系的视觉线段。
- **当前会话**: 被宿主选中、用户当前正在查看（或在其它页面停留前最后查看）的会话，其对话显示在主区域时为前台态，主区域显示全局面板时为后台态。
- **前台态**: 当前会话的对话正显示在主区域时的卡片呈现，以最强描边、外环与光晕标识，是窗格最高视觉层。
- **后台态**: 当前会话被选中、但主区域显示全局面板时的卡片呈现，保留选中色相与可辨描边，视觉强度低于前台态。
- **活动会话**: 正在运行、或正在等待用户行动（阻塞等待、完成提醒或错误提醒）、或存在活动后代的会话，出现在窗格顶部活动区。
- **委托周期**: 自会话出现活动后代起、至后代全部结束且处理其结果的回合完成止的连续时间段，期间母会话卡片保持运行中呈现、进度按同一锚点连续推进、完成提醒暂不生效。
- **最近会话**: 当前非活动、仍被会话服务列出的主会话（不含子代理），按最后活动时间从新到旧出现在窗格下方最近历史区。
- **活动区**: 窗格上部仅承载活动卡片的区域。
- **历史区**: 窗格下部承载最近会话卡片的区域，历史卡片按最后活动时间从新到旧分批呈现。
- **历史分页**: 历史区按排序结果划分的显示批次，每批最多 10 条，已呈现批次保留，用户激活底部「加载更多...」按钮后追加下一批。
- **宿主列表时间**: 宿主会话列表带入的更新时间——会话创建时刻与最后一条真人用户消息时刻中的较新者。
- **最后活动时间**: 会话最后一轮回复结束时刻与宿主列表时间中的较新者，无已完成回合时即宿主列表时间。
- **相对活动时间**: 当前时间与最后活动时间的非负差值按分钟、小时、天、周、月或年分级形成的近似时长文案，用于快速判断会话新旧。
- **进入状态时刻**: 会话进入当前等待行动状态的时刻，阻塞等待以等待开始时刻计、完成提醒与错误提醒以最近一次回合结束时刻计，不可得时为空。
- **状态年龄**: 当前时间与进入状态时刻的非负差值按相对活动时间分级形成的文案，显示在等待行动卡类型胶囊右侧。
- **活动卡片**: 窗格中表示一个活动会话的条目。
- **最近卡片**: 窗格中表示一个最近会话的条目。
- **轮内状态**: 会话单个回合进行中的状态，含工具名、流式或推理回复、输出 token 计数与近似输出速率、已运行时长、工作项时间线与阶段进度，进入等待行动后保留停止前最后已知的统计字段。
- **最近回合耗时**: 最近一个已结束回合的起止时刻差值，不含回合结束后的等待时间，显示在等待行动卡与最近卡片 token 统计行的最右侧。
- **最近回合统计**: 最近一个已结束回合的输出速率、缓存命中率、计费输入 token 数、输出 token 数与固定耗时，缺失字段为空，全部不可用时不占显示行。
- **累计运行时长**: 会话从第一个回合到当前为止全部回合运行过程时长的累计值，只含运行过程时间、不含回合间空闲与回合内阻塞等待，运行中会话含当前开放回合的实时已耗时。
- **输出速率**: 会话生成输出的速率（token/秒），由累计输出 token 与耗时派生，以 tok/s 形式显示且不带近似符号。
- **轮内进度**: 运行卡对回合推进程度的百分比估计，由已耗时按 y = t/(t+k) 映射、半衰期 k 按最新实测输出速率校准，允许随速率回落而回退。
- **加载指示**: 数据在途时在区域或卡片字段位置显示的活动图标，表示该处正在拉取数据，与空态互斥。
- **工作项**: 主会话窗口中按显示顺序出现的一个可识别工作单元，含图标语义、文字、详情与状态。
- **工作项时间线**: 活动卡中按主会话窗口实际显示顺序派生、以折叠时间线呈现的工作项序列，当前执行工作项由原生会话推送持续更新。
- **当前活动行**: 运行中会话时间线内代表真实在飞 partial、running call 或当前执行分组的显示行，须保留其身份、文字与执行中状态并置于末行。
- **工作项分组**: 折叠时间线中的一个显示行，聚合相邻连续工作过程工作项（工具调用、思考或上下文注入）的组标题、摘要与聚合状态。
- **折叠时间线**: 工作项时间线的唯一呈现形态，相邻连续工作过程合并成分组行呈现，为窗格自有数据层派生、不依赖折叠插件存在。
- **显示档位**: 卡片呈现的完整、中间（默认）与紧凑三档形态，经标题行工具区按钮按紧凑→中间→完整循环切换，作用于活动区与历史区全部卡片并持久化。
- **紧凑显示**: 显示档位的最简档，每张卡片仅保留标题行（状态点、标题、后台任务数量注与行尾工作区名胶囊，完成提醒卡另附确认按钮图标），其余行隐藏。
- **命中区**: 可交互元素接收指针或触点事件的区域，窗格以可见的视觉盒与经透明外扩的可点命中盒双层口径描述，命中盒可与相邻行视觉重叠。
- **模型上下文**: 会话当前主窗口使用的模型名称与 reasoning level，缺失字段保持空值、不以 preset 名称冒充；子代理模型溯源指子代理卡标题行右缘从会话日志解析的模型名称与 reasoning effort。
- **指令锚行**: 停留于时间线第一行的最近一条非空文本用户输入行，占用一个总预算名额，其后显示最近最多 3 个工作显示行，更近的非空用户输入行升至第二行时取代它。
- **物理首行**: 文本按原始换行拆分后第一个去除首尾空白且非空的行，不存在时为空。
- **消息预览**: 最近卡分别展示的最近用户消息与最近 agent reply 的物理首行，不等同于完整正文。
- **后台任务**: 会话经任务注册表发起、生命周期独立于会话回合的后台工作，含标识、工具类型、标签、状态与启止时刻。
- **在跑后台任务**: 状态为运行中或停止中的后台任务，其存在只令归属主会话的卡片标注任务数量，不改变该会话的活动归属、呈现类别与完成或错误提醒判定。
- **等待行动**: 会话因阻塞等待、完成提醒或错误提醒而需要用户关注的状态。
- **阻塞等待**: 会话因待确认、待审查或待回复而停止不前、必须等用户答复才能继续的等待行动状态，以金色卡面和「类型胶囊 + 正文」呈现并脉冲闪烁。
- **完成提醒**: 主会话存在已完成且尚未被确认的回合时的等待行动状态，以绿色成功色卡面与「已完成」胶囊呈现，仅由用户显式确认解除。
- **错误提醒**: 主会话最近一个回合以不可恢复错误结束时的等待行动状态，以红色错误卡面与「错误」胶囊呈现，随新回合结束覆盖解除、不提供确认按钮。
- **完成确认**: 解除完成提醒的显式用户动作，激活确认按钮后写回宿主并在所有客户端同步生效，打开会话或切换当前会话不构成确认。
- **确认按钮**: 完成提醒卡上可访问名称为「移入历史」的显式确认控件，完整与中间呈现为末行文字按钮、紧凑显示为标题行行尾图标按钮，仅完成提醒卡提供。
- **活动总览窗格**: 桌面形态下真实占据中间列左侧的贴边列、移动形态下的抽屉，承载活动区与历史区两段列表。
- **窄条**: 桌面列折叠后的形态，不占用主会话宽度，显示活动计数并可点击展开。
- **抽屉**: 移动断点（窗口宽度 ≤ 767px）下窗格的收纳形态，默认隐藏在屏外，经开关展开与收起。
- **宿主侧栏抽屉**: 外壳自身在移动端的侧栏抽屉（会话与工作区导航），与窗格抽屉无关。
- **宿主侧栏展开按钮**: 移动壳层在屏幕左上角提供、用于打开宿主侧栏抽屉的按钮，会话页与 hero 页各有一种形态。
- **移动断点**: 窗格从贴边列切换为抽屉的视口宽度阈值（767px）。
- **触屏形态**: 主输入无 hover 且主指针为触屏的设备形态，属输入能力口径，与视口口径的移动断点相区分。
- **外壳**: DeepSeek Harness Web 的应用框架，包含 AppFrame 三栏布局与槽座。
- **会话视图**: 外壳在主槽座渲染的会话页面（hero 或已打开的会话），与全局面板互斥。
- **全局面板**: 外壳在主槽座渲染的非会话页面（插件页、定时任务页、第三方市场页等），占屏时替代会话视图。
- **回合统计宿主侧**: 插件在宿主进程内订阅会话事件配对回合起止、累计 busy 总时长并经 HTTP/SSE 只读下发的半端，是累计运行时长的唯一持久化归属。
- **完成确认宿主侧**: 插件在宿主进程内登记回合结束时刻、持久化确认游标并经 HTTP/SSE 通道下发与接收确认写回的半端，是完成确认状态的唯一持久化归属。
- **活动状态模型**: 把宿主会话快照归一化为活动区与历史区条目、轮内状态文案的领域模块。
- **窗格渲染器**: 负责窗格挂载、双区绘制、滚动、跳转、桌面折叠与移动端抽屉的领域模块。
- **E2E 验证基建**: 仓库级验证设施，由 mock LLM 的 E2E 剧本服务、隔离测试环境启动器与浏览器端到端 spec 组成，只承载验收点的自动化锚定。
- **隔离测试环境**: 以独立临时宿主数据目录与系统分配空闲端口启动的 dsh web 实例，预置配置指向 mock LLM，与日常实例互不影响。
- **E2E 剧本**: mock LLM 服务按测试场景返回的预编排 SSE 响应序列，由用户消息关键词选择，在浏览器端到端测试中确定性制造会话活动。

## 实体与关系

### 关系

- **母会话**（父）—拥有→**子代理**（子）：由母会话派生，形成层级树。
- **工作区**（组）—包含→**会话**：按会话工作目录归属，决定主会话卡片在窗格中的顺序。
- **活动状态模型**—消费→**会话**：读取会话服务快照，产出活动卡片条目与最近卡片条目。
- **活动状态模型**—消费→**轮内状态**：把运行中会话的原生订阅快照归一为运行统计与工作项时间线。
- **活动状态模型**—消费→**模型上下文**与**消息预览**：把原生会话快照与投影归一为卡片元数据。
- **窗格渲染器**—承载→**活动卡片**与**最近卡片**：在活动总览窗格的活动区与历史区中绘制与交互。
- **活动总览窗格**—形态→**抽屉**或**窄条**：随移动断点或折叠控制在贴边列、抽屉、窄条之间切换。

### 生命周期

- **活动卡片**的生命随其**会话**的活动性：会话进入运行或等待行动时出现，经确认或新回合更替转入历史区，子代理结束后即消失。
- **会话**在**活动区**与**历史区**之间迁移：不再满足活动判定时转入历史区，重新满足时回到活动区，迁移由每次渲染的数据派生并以移动动画呈现。
- **轮内状态**订阅随会话进入运行态建立，随会话停止运行或插件卸载断开。
- **活动总览窗格**随外壳挂载而创建、随外壳重挂载而重建且不重复，随插件卸载而移除。
- **窗格**内容除确认按钮的确认写回外不写回宿主，会话状态的变化方向恒为宿主服务到活动卡片。

## 跨模块不变量

- 主会话卡片按所在工作区的侧栏顺序排布，未归入任何工作区的主会话排在所有工作区之后并保持出现顺序。
- 子代理卡片与后台任务卡片始终跟随其母会话卡片，以缩进与层级连接线表达直属关系，深度大于母会话。
- 会话存在活动后代时，其全部有效母会话必须在活动区保持运行中呈现，且不得同时进入历史区。
- 等待行动的会话以区别于运行中的样式呈现，阻塞等待用金色、完成提醒用绿色、错误提醒用红色，并以「类型胶囊 + 正文」呈现且脉冲闪烁。
- 存在等待行动时，列头、窄条与移动端开关三处数量胶囊以与等待卡末行相同的固定节奏同步闪烁。
- 三类等待卡的标题状态点均不闪烁，描边与光晕强度一致，且底色、描边与外环均不强于当前会话的前台态呈现。
- 当前会话卡片恒为窗格最高视觉层，前台态的外环宽度、光晕半径与描边不透明度均大于等待提醒卡与后台态。
- 后台态保留蓝色可辨但明显弱于前台态，不以整卡底色或彩色铺面压过等待提醒卡。
- 一个会话要么在活动区、要么在历史区，绝不同时出现于两区。
- 最近会话的判定只依赖会话服务快照中的会话状态与最后活动时间戳，不依赖插件私有记录。
- 历史分页只改变呈现批次，不改变候选集合与排序口径。
- 每个会话最多进入一次历史区，候选耗尽后不再重复加载，滚动到底部本身不触发追加。
- 轮内状态订阅数量与运行中会话数量一致，会话停止运行或插件卸载后订阅归零。
- 活动条目顺序在快照未变化时必须稳定，重复渲染不产生可见变化。
- 窗格不得改写宿主内容、删除宿主节点或修改会话与工作区数据，只能滚动自身列表并适配桌面布局。
- 桌面窗格在会话视图与全局面板之间的页面切换期间保持显隐与展开、收起形态不变。
- 工作项时间线必须使用主会话窗口的实际工作顺序，总行数不超过 4。
- 存在指令锚行时，其后为最近最多 3 个工作显示行，运行中的当前活动行保留在末行、不得被锚行裁剪或用旧尾行冒充。
- 工作项分组必须以用户输入项与正文工作项为硬边界，不得跨边界合并。
- 窗格功能不得依赖折叠插件存在。
- 指令锚行占用一个总预算名额，更近的非空用户输入行升至第二行时取代旧锚行且其后各行上移，空文本用户输入行不停留不取代。
- 模型上下文不得以预设名称冒充模型，模型或 reasoning level 缺失时保持空白。
- 模型选择在显示期间变更时，卡片模型上下文跟随当前选择更新，不停留旧值。
- 最近卡的最近回合统计位于助手消息预览之后、活动时间之前，缺失字段不伪造，全部不可用时隐藏该行。
- 运行中会话进入等待行动时，等待卡保留进入等待前最后已知的输出速率、缓存命中率、计费输入与输出 token，等待期间冻结。
- 显示档位是裁剪的唯一输入，紧凑档不为不可见内容传输会话日志数据或构建其 DOM。
- 紧凑档下主会话不建立或保持会话日志窗口、不发起日志分页读取，子代理日志窗口不受裁剪。
- 当前会话的日志窗口由外壳持有，窗格不对其释放，只在该会话不再是当前会话后的渲染期释放。
- 轮内状态订阅、回合统计与完成确认通道、会话与工作区列表订阅在任何档位下保持正常。
- 被裁剪的数据在切回更高档位后按既有渐进加载语义恢复。
