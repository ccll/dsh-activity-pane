# C-010 运行卡以工作项时间线承载运行轨迹，删除独立的流程节点轨迹 trace

日期: 2026-08-22

#### 上下文
DESIGN 与 PRD（R-01-009/AC-07、AC-09）描述运行卡显示 `buildTrace` 产出的「流程节点轨迹」（已定案工具调用 + 当前阶段），但渲染层实际以 `timeline?.length ? timeline : trace` 取舍，工作项时间线几乎恒非空，trace 被遮蔽——每次渲染仍为其付出 O(窗口节点) 计算，map 与 code 漂移。

#### 决策
删除 `buildTrace` 与条目的 `trace` 字段：运行轨迹由工作项时间线（R-01-012，含状态/耗时/白名单摘要/竖线圆点呈现）单一承载；R-01-009/AC-07、AC-09 改写为工作项时间线语义，`cardSignature` 移除 `trace` 分量。

#### 被否方案及原因
- 恢复 trace 与时间线双轨显示：信息冗余、卡片更高，且保留每帧 O(n) 的全窗口节点过滤；时间线已覆盖节点状态、耗时与白名单摘要，双轨收益不抵成本。

#### 影响面
R-01-009 / 活动状态模型、窗格渲染器
