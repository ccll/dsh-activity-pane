# 路线图

## 愿景

在 DeepSeek Harness Web 中，把分散在侧栏各工作区里的运行中会话与等待用户行动的会话收拢到一个可贴边、可滚动的窗格：用户一屏掌握全部需要关注的会话并一键直达，集成方无需任何第三方插件即可安装、卸载并干净回退。

## 目标

- **一屏掌握与直达**: 用户无需逐会话翻看即可掌握所有运行中与等待行动的会话，并可直达目标会话。
- **原生依赖与可逆卸载**: 插件仅依赖 DSH 原生会话与工作区服务，可脱离任何第三方宠物插件独立运行，卸载可逆。
- **双形态可用**: 窗格的桌面与移动形态保证独立滚动、不遮挡主会话，外壳重挂载后自动恢复。

## 非目标

- **完整正文与历史**: 不渲染会话完整正文与完整历史；窗格只展示有限的工作项与消息首行预览，并提供跳转。
- **会话语义操作**: 初版不提供完成确认以外的会话语义操作，如重命名、取消、队列编辑、直接响应阻塞等待项。
- **装饰性呈现**: 不做桌面宠物、主题动画等装饰性呈现。
- **第三方状态路由**: 不复用或代理第三方插件的状态路由与轮询协议。

## 里程碑

五个里程碑均已达成。

### 会话总览与直达

方向: 用户打开窗格即能一次掌握全部活动会话与等待行动，并直达目标会话。

- 活动区一次列出全部运行中与等待行动的主会话，状态变化自动更新。
- 阻塞等待、完成提醒与错误提醒以「类型胶囊 + 正文」呈现并脉冲提醒。
- 子代理以缩进与层级连接线跟随母会话，工作区徽标显示归属。
- 活动区与最近历史区分区呈现，最近卡给出用户与助手消息预览。
- 卡片激活即切换当前会话并高亮当前会话，数量徽标以「运行中数/活动主会话总数」呈现，窗格独立滚动。

### 卡片信息纵深

方向: 不打开会话即可读懂每个会话正在做什么、最近做过什么与投入了多少运行时间。

- 运行卡显示模型上下文、折叠工作项时间线、工具摘要与回合进度。
- 运行卡统计行显示输出速率、缓存命中率、计费输入与输出 token。
- 等待卡沿用最近工作项轨迹，并冻结进入等待前的统计字段。
- 卡片显示最近回合耗时与累计运行时长，紧凑档隐藏累计值。
- 后台任务以数量注与子卡呈现，不改变会话的活动归属。

### 桌面与移动形态

方向: 窗格以桌面贴边列与移动抽屉两种形态融入外壳，可折叠、可调宽、不遮挡主会话。

- 桌面贴边列真实让位，主区域在会话视图与全局面板之间切换时形态不变。
- 标题区整体折叠为窄条，窄条整条可点展开。
- 右缘手柄拖拽调宽并夹取 200–480px，刷新后恢复。
- 移动端为默认隐藏的抽屉，活动开关嵌入会话标题行，点击遮罩收起。
- 标题行两端常驻仓库入口与档位切换按钮。

### 呈现档位与浏览节奏

方向: 用户按信息密度需要切换呈现档位，窗格只为可见内容付出数据与渲染代价。

- 完整、中间、紧凑三档循环切换，当前卡位置锚定，档位持久化。
- 历史区每批 10 条渐进呈现，底部按钮手动加载更多。
- 加载指示区分「正在加载」与「没有数据」，字段就绪即就地填充。
- 回到顶部按钮在滚动离顶后出现，移动抽屉内同样可用。
- 紧凑档不建立会话日志窗口、不发起日志分页读取。

### 插件独立性与健壮性

方向: 插件只依赖宿主原生服务独立工作，卸载与外壳重挂载皆干净可逆。

- 只消费宿主原生会话、工作区与任务服务，不依赖第三方插件状态路由或轮询。
- 外壳重挂载后自动恢复窗格，且不产生重复实例。
- 渲染签名去重，状态未变时跳过可见 DOM 写入。
- 卸载时移除注入的元素、样式与监听，轮内订阅随运行结束或卸载断开。

## 后续方向

- 空闲期按需断开长连接，需权衡完成提醒徽标的即时性。
- 移动端抽屉背景模糊降级为低模糊或实色，需权衡可观察的视觉设计。
- 收敛流式派生与列表渲染的增量成本，减少长会话与多会话下的重算。
- 补充插件市场一键安装入口，降低首次安装成本。
- 为 README 增加常见问题与故障排查章节，待真实问题样本积累后写。
- 补齐触屏形态下的连接自愈触发面，按实测命中的形态立项。
