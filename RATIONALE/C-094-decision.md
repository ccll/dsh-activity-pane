# C-094 开关恒在抽屉后被遮挡：锚缺失期间保留原位，去除宿主抽屉隐藏检测

日期: 2026-10-10

#### 上下文
T-167 层级归位后东家真机实测仍有瑕疵：hero 页弹出并收回宿主左边栏抽屉，开关延迟一小段时间后突然出现。根因有二：宿主抽屉打开时壳层在 drawerOpen 翻转的同一 reconciler 遍内移除 ⊡，落位守卫锚不可测即摘除开关；关抽屉时属性先翻转、重挂 ⊡ 晚于翻转（T-167 已探明），恢复靠帧观察器翻转即检 + 400ms 复检，开关在这段窗口不在文档。T-165 引入的宿主抽屉 visibility 隐藏是层级逃逸时代的补偿，层级归位后遮挡已由层级承载，隐藏本身成为突变来源。东家指示：开关应一直在抽屉后面、只是被挡住，而不是摘除后凭空重现；同时开关外层胶囊壳（底色、描边、投影）去除，只留内部涂色的计数胶囊。

#### 决策
开关一经落位即常驻。锚缺失期间保留原位几何，由抽屉与遮罩在层级上遮挡。摘除仅限两处：壳层结构缺失且开关已挂载、cleanup 卸载。未落位不渲染不变。宿主抽屉隐藏检测随层级归位整体摘除，细节由 SOLUTION 承载。关抽屉后的落位重锚由帧属性观察承载。外层胶囊壳去除，可见形态即计数徽标本体。

#### 被否方案及原因
- 保留隐藏、只修检测时序：检测本质是离散采样，无论多密都与抽屉动画错拍，突变只会推迟不会消失，否。
- 以壳层抽屉状态属性为保留条件：关抽屉时属性翻转早于重挂 ⊡，该窗口内会误判为「抽屉未开」而摘除，重现延迟 bug，否。
- 锚缺失即一律摘除、仅加快复检：复检节奏再快也存在无锚窗口，凭空重现仍在，否。
- 保留外层壳仅调淡样式：东家明确要求去除壳体只留内部胶囊，调淡不满足，否。
