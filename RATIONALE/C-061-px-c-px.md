# C-061 时间线圆点改为实际 5px 盒（修订 C-036 的 7px 同盒）

日期: 2026-08-28

#### 上下文
C-036 以 7px 承载盒内的 5px 实心核解决跨 DPR 圆心相位与硬停色八边形问题，但 1px border 加外扩 box-shadow 使节点整体可见轮廓达到 7～9px。东家实测其与标题前 7px 状态点看起来一样大，不符合 R-01-009/AC-09 的 5px 视觉层级，明确要求时间线圆点整体缩小且标题点保持不变。

#### 决策
- 时间线节点改为实际 5×5px border-box，使用 `left: 1px` 保持圆心 x=3.5；1px 竖线继续使用 `left: 3px`，与时间线点和 7px 标题点同圆心。
- 1px 半透明 border 在 5px 盒内承载外环；普通节点删除外扩 1px box-shadow，running 节点仅保留状态光晕与脉冲。
- 继续使用实体背景、`border-radius: 50%` 与 `background-clip: padding-box` 原生裁剪，不恢复硬停色 radial-gradient；DPR 验收同时检查平滑圆度、同圆心与 5px/7px 尺寸层级。

#### 被否方案及原因
- 维持 C-036 的 7px 同盒、只缩小内部实心核：整体外环轮廓仍与标题点同大，不能解决东家指出的视觉问题。
- 同时缩小标题点：会降低标题状态的识别度，且超出本次仅调整时间线节点的范围。
- 新增嵌套圆点 DOM 以分离承载盒与视觉核：纯 CSS 的 5px 伪元素已能保持 x=3.5 圆心，无需增加节点与渲染逻辑。
