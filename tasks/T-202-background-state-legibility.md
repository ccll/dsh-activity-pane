# T-202 后台态当前会话的可辨度加强（东家视觉反馈）

状态: active
类型: 缺陷修复
风险等级: major
风险面: 对外行为（卡片视觉层级与前台/后台态对比）
关联需求: R-01-006/AC-03、AC-06；R-01-002/AC-08（等待三类强度上限）
决策依据: C-104（视觉优先级：前台态 > 等待卡 > 后台态）

## 背景与目标

- 背景: T-199 把后台态压到描边 32%/30%、外环 1px 14%/12%、光晕 10px 10%/8% 且无内发光，
  以满足「不强于等待卡」；东家实际观感反馈蓝框几乎看不出来，与 DOMAIN「后台态保留选中色相
  与可辨描边」的承诺不符。
- 目标: 后台态明显可辨（一眼能认出是当前会话）但明显弱于前台态；描边不高于等待三类卡
  （34%），不靠整卡铺色；前台态与等待卡不变。

## 差距评估

- 观感: 32% 描边 + 1px 14% 外环在深色卡面上对比不足；无内发光时卡片缺少「蓝色附着」的第二层线索。
- DOMAIN: 后台态承诺「保留选中色相与可辨描边」；实现只满足数值上限、未满足可辨下限。
- 契约: check.mjs 精确串与 e2e 断言绑定旧值（32%/30%、1px、10px），改动须同步。
- 边界: AC-03 要求后台态不强于等待卡，因此描边 alpha 不能越过 34%；加强必须落在环宽、柔光与内发光。

## 收敛方案

- 无分叉点: 数值区间由东家指令（更强但不如前台夺目）与 AC-03 上限（描边 ≤ 等待卡 34%）共同约束，方案唯一。
1. 描边: 深色 33%、浅色 31%（均低于等待三类卡 34%）。
2. 外环: 1.5px 34%/30%（形状与前台同宽、强度约为其一半）。
3. 柔光: 14px/12px 24%/18%（前台为 16px 45%/30%）。
4. 轻内发光: 10px 10%/8%（前台 20%/12%），让卡片有淡蓝附着而不整卡铺色。
5. 前台态、等待三类卡、数量徽标均不变；check.mjs 契约串与 visual-hierarchy 断言同步。

## 测试计划

- `node scripts/check.mjs`: 深/浅后台态契约串（描边、1.5px 环、柔光、内发光）与「描边不高于等待卡」断言。
- `node e2e/run.mjs visual-hierarchy`: 后台态描边 ≤0.34 且 < 完成卡；1.5px 外环、14px 柔光、inset；光晕半径小于前台；浅色后台态 ≤0.34。
- 回归: compact-density（卡片计数与迁移）、desktop-layout（面板切换）、auto-update/error-reminder（等待卡与徽标配色不变）、long-list（滚动锚定）。
- 观感: 深/浅主题后台态截图与前台态对照，交东家确认「明显区分但不如前台夺目」。

## 自查清单

- 边界：描边 33%/31% 低于等待卡 34%；外环与前台同宽但 alpha 约为其一半；柔光半径小于前台 16px。
- 异常路径：后台态规则仍位于等待当前卡组合之后（0-4-0 后定义者胜），完成卡即当前会话时同样转后台态。
- 回归影响：前台态与等待三类卡数值未动；数量徽标同值断言仍通过；`data-current` 语义与滚动锚定不变。
