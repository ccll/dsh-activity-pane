# C-062 时间线节点恢复 7px 同心承载盒与半透明外围（修订 C-061）

日期: 2026-08-28

#### 上下文
C-061 将时间线节点改为实际 5px 盒后，页面绝对几何中心测试虽通过，东家在真实页面仍观察到竖线没有从所有圆点的视觉中心穿过，且此前小圆外的半透明外围消失。根因是 5px 时间线盒与 7px 标题盒在不同 DPR 下采用不同光栅取整相位，数学中心相同不等于视觉质心同相；同时删除普通节点外扩 box-shadow、又把 1px border 放进 5px 盒，实际只留下 3px 实心核且外围难以辨认。该现场证据翻案 C-061 对 7px 同盒方案的否决。

#### 决策
- 时间线节点恢复 7×7px 承载盒（`left: 0; top: 3px`），与 7px 标题点和 `left: 3px` 的 1px 竖线共享 x=3.5 圆心及同一光栅相位。
- 承载盒以 1px 半透明 border 留出 5px 实心核；普通节点恢复 1px 半透明外扩 box-shadow，running 节点恢复同色外围并保留 6px 光晕与脉冲。
- 自动化以真实浏览器验证 7px 同盒、5px 核、页面绝对同心、普通外围与 running 动效；DPR 1/1.25/1.5/2 的视觉质心与平滑圆度继续人工放大验收。

#### 被否方案及原因
- 继续使用实际 5px 圆盒并微调 `left`：只能针对单一 DPR 做光学补偿，无法让不同 DPR 与 7px 标题盒保持同一光栅相位。
- 给 5px 圆盒增加外围但不恢复同盒：可恢复 halo，不能解决竖线视觉偏移。
- 新增嵌套 DOM 分离承载盒与实心核：现有伪元素的 border/background/box-shadow 已能同时承载 7px 盒、5px 核和外围，无需增加渲染节点。
