# C-026 工作区徽标色相按工作区身份哈希派生（无状态），而非调色板取模或黄金角有序分配

日期: 2026-08-26

#### 上下文
R-01-003/AC-08、AC-09 要求工作区徽标颜色同一工作区恒同色、不同工作区可区分、跨刷新稳定。存在三条认真候选路线。
#### 决策
以工作区身份（路径优先、名称兜底）为唯一输入的纯函数派生色相：djb2 哈希 → 十二槽 30° 量化 + 哈希低位 ±10° 抖动，输出 [0,360) 整数；无状态、无持久化。
#### 被否方案及原因
- 固定调色板 + 哈希取模：色板内可保证区分，但工作区数超过色板或撞哈希时必然重复，且引入一套需逐主题校验的固定色值。
- 黄金角（137.5°）递推分配：区分度数学上最优，但依赖工作区出现顺序并需持久化映射，增删工作区后颜色漂移，不满足跨刷新稳定。
#### 影响面
