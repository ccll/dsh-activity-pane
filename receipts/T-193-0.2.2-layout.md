# T-193 DSH 0.2.2-rc.1 全局面板布局回执

## 运行

- 宿主: `@deepseek-ai/dsh@0.2.2-rc.1`，临时 `DSH_HOME`（`/tmp/t193-home022` 修复组、`/tmp/t193-home022b` 基线组），web profile 以本地目录安装本插件，内置 Plugins 页作为全局面板。
- bundle: 基线组为 `main` v0.19.1（`d23af5b`）预构建产物；修复组为 `t193-native-panel-layout` 分支 T-193 实现的工作树产物。
- 浏览器: Playwright headless Chromium，1280×800，桌面端；两侧均只打开应用并进入全局面板，不发送消息。
- 刺激: 在原生页根（`SECTION`）注入 `container-type: inline-size`，复现 #5 的固有宽度为 0 条件；未取得真实 dsh-market 入口，故以同形刺激替代。

## 结果

| 阶段 | 中列方向 | 页根 | 窗格 |
| --- | --- | --- | --- |
| 基线·全局面板 | row | `SECTION` 96px、`container-type: inline-size` | `display:flex`、280px |
| 修复·全局面板 | column | `SECTION` 1000px、`container-type: inline-size` | `display:none`、0px |
| 修复·返回会话 | row | 会话根（`DIV`，`display:contents` 包装层） | `display:flex`、280px |

## 结论

- 0.2.2-rc.1 下，基线行布局把带 inline-size containment 的全局面板压成 96px 窄条；T-193 判据识别宿主 `data-global-panel` 标记后恢复外壳列布局，面板占满中列 1000px，窗格与开关隐藏。
- 返回会话后行布局、窗格显隐与 280px 宽度恢复；修复组未观察到布局残留。

## 限制

- 真实 dsh-market 页面未复现（其入口未出现在侧栏），本回执以内置 Plugins 页 + 同形 containment 刺激验证布局判据，不覆盖市场插件自身的页面代码。
- 探针不发送消息，不覆盖流式、恢复与移动端路径；这些路径由 0.2.0 e2e 与 `pnpm verify` 承载。
