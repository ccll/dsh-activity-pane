# C-087 移动端「活动」开关以布局子项嵌入宿主头部，而非继续浮层定位

日期: 2026-10-09

#### 上下文
移动端开关自 T-029 起以 `position:fixed` 固定在头部左上角硬编码坐标（按当时侧栏切换按钮 28px 宽推算 `left:44px`）；宿主侧栏切换按钮后变为 36×36、头部内容演进，开关再次压住会话标题 crumb 按钮，违背 R-01-008/AC-04「不遮挡其它界面控件」。继续调坐标是对宿主几何演进的持续追赶，每代宿主都可能复发。

#### 决策
开关常态作为宿主头部标题行的布局子项参与排布（插于行内标题簇之前），宿主内容真实让位；宿主头部不可得时回退 fixed 浮层兜底形态，兜底 left 按侧栏切换按钮实测右缘动态写入。打开抽屉时嵌入态以 `visibility:hidden` 留位隐藏，标题行不因开合重排。

#### 被否方案及原因
- 浮层仅换位（右下角 composer 上方等）：仍是覆盖式呈现，继续遮挡滚动内容；composer 高度随软键盘与附件条多变，新坐标同样易失配。
- 继续浮层并动态避让（量测宿主控件后挪位）：需要持续追踪宿主几何并抢在宿主重渲染前校正，复杂度与失配风险都高于让宿主布局自行安排。
- 嵌入并改 icon-only 以省头部宽度：与 AC-04「文案为活动」冲突，需先走需求变更；当前头部宽度可容纳，不为此扩需求面。

#### 影响面
R-01-008 / 窗格渲染器（T-160）
