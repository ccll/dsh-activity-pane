# C-101 全局面板占屏时收起活动窗格、主区域让给面板

日期: 2026-11-16

#### 上下文
#5 报告在 DSH 0.2.2 上安装 dsh-market 后，市场页被压成 60–101px 窄条；#6 定位窗格桌面布局无条件把中间列切为行方向、只在会话视图存在时给会话根 flex，原生全局面板占屏（会话视图不在屏）时没有回退，面板内在宽度被压到 0。修复有两条可观察路线：收起窗格把主区域整列让给面板，或保留窗格并给面板根弹性尺寸。东家 2026-11-16 拍板前者；隔离探针显示后者在 0.2.2 内置 Plugins 页仅 720px，不能兑现「面板占满主区域」的预期。

#### 决策
桌面全局面板占屏且会话视图不在屏时，中间列恢复外壳默认列布局、窗格与开关收起，主区域让给面板；用户返回会话视图时恢复贴边列、窗格与既选宽度/折叠形态。判据优先读宿主 `data-global-panel` 标记，0.2.0 无标记时回退到会话滚动区缺失（东家拍板，2026-11-16）。

#### 被否方案及原因
- 保留窗格并给原生页根 `flex: 1 1 0%; min-width: 0`：窗格仍占用 280px，0.2.2 内置 Plugins 页实测仅 720px 宽（中列 1000px），不满足 #5 的全宽预期；窄窗格与面板分栏还会在截图类面板里挤压内容。
- 只补会话根 flex 回退、不隐藏窗格：原生页没有会话根，回退无处落点；把面板根当会话根会继续行布局，面板与窗格并排，不能占满主区域。
- 等待宿主修复 keyed main 槽的挂载策略：宿主行为不在本插件控制范围，且 0.2.0 已存在无会话视图的原生页；插件必须自洽处理。
- 保留窗格但收缩到窄条：窄条仍占宽，且原生页期间用户无法操作窗格内容，收益低于全宽让位。

#### 影响面
R-01-007 · 窗格渲染器（T-193）
