# C-018 用户指令行标识以整行浅绿平底取代虚线 outline

日期: 2026-08-25

#### 上下文
R-01-018 落地时以 1px 虚线 outline 标识指令槽位与时间线用户行，东家实际使用反馈虚框过丑且过于抢眼，要求换成不抢眼的提醒视觉。蓝色已被 running 状态圆点占用（东家明确不可再用于用户消息），绿/红/橙亦各有状态语义，标识手段须在状态色体系之外或与既有语义相容。

#### 决策
槽位与时间线用户行以图标+文字整行浅绿平底标识（#58c98f 透明度 10%、4px 圆角）；全部时间线图标统一 14px 盒 + 1px padding 保证字形 12px、圆心对齐；助手正文行（robot）不设底色。

#### 被否方案及原因
- 图标或轨道圆点变色：占用/混淆状态色语义（蓝=进行中、绿=完成），东家明确否决蓝色用于用户消息。
- 图标圆形浅底：与用户行并存时感知尺寸不一致（亮度辐照错觉 + 色环厚度差异），且圆形与状态圆点同形易混。
- 圆环/圆角方环：14px 盒内字形顶边显挤；1px 描边在小尺度下辨识度不稳定。
- 左起 80%→0 渐变底：左缘过实、强弱不均，东家试看后否决。
- fit-content 紧凑色块 + 直角：东家试看后认为不如整行圆角平底。
- 助手行同系弱蓝/紫底：与用户底区分度不足或引入新色相噪音，最终只保留用户行标识。
