# C-032 同屏消解由 24° 小步推移修正为 48° 最小感知间距 + 111° 黄金步进跳转（修订 C-031）

日期: 2026-08-26

#### 上下文
C-031 获批后、实现前，用东家真实可见路径干跑 24° 小步方案：212°、238°、273°、296° 只变成 212°、238°、273°、320°，仍全部位于蓝—紫—洋红区，无法解决「只有蓝色和紫色」的观感。新证据表明仅防数值近邻不足以跨色区分散。

#### 决策
- 最小感知间距由 24° 提高为 48°，距离按 CSS hue 的圆周距离计算。
- 冲突候选不做同值小步挪动，改为沿 291° 避红弧按 111° 黄金步进跳转并回绕；真实集合因此得到 273°（紫）、116°（绿）、212°（蓝）、58°（橙）。
- 候选最多遍历避红弧的 291 个整数色相，超过约 6 个同屏工作区时允许尽力而为并保证有限终止。

#### 被否方案及原因
- 保持 C-031 的 24° 步进：真实数据已证明仍聚集在蓝紫区，不能兑现东家观感目标。
- 只把阈值提高到 48°、仍按 48° 步进：冲突色沿原色区缓慢移动，跨色区效率低；111° 黄金步进用一次跳转即可获得明显色区差异。
