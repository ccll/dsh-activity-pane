# C-064 待回复提示改用「提问」胶囊与语义化 HTML 列表（修订 C-041、C-043）

日期: 2026-08-29

#### 上下文
C-041 将待回复卡的胶囊改为「问题」，并把问题正文拼成带 `Q`/`Qn` 前缀的多行纯文本；C-043 延续该末行结构。东家现要求胶囊使用动作语义「提问」，问题正文由 HTML 原生列表表达：单问题使用 bullet list，多问题使用编号列表。纯文本前缀只能模拟视觉效果，不能向浏览器与辅助技术暴露列表结构。

#### 决策
- 待回复卡类型胶囊文字由「问题」改为「提问」，问号图标、金色阻塞语义与脉冲行为不变。
- 活动状态模型保留结构化问题条目及原始位置，不再生成 `Q`/`Qn` 前缀字符串。
- 窗格渲染器仅有一个可展示问题时使用 `<ul><li>`，多个可展示问题时使用 `<ol><li value>`；编号继续对应问题原始位置。
- 最多显示 3 个问题；仍有可展示问题时追加隐藏 marker 的省略项。
  - 问题正文、header 回落、物理首行与尾冒号剥除规则不变。
- 动态问题文字只通过 `textContent` 写入列表项，不进入 HTML 解析路径。

#### 被否方案及原因
- 只把胶囊改为「提问」，继续保留 Q 行纯文本：未兑现东家明确要求的 HTML 列表元素，也缺少原生列表语义。
- 单问也使用编号列表：单个问题不存在排序辨识需要，东家明确要求 bullet list。
- 多问使用无序列表并手写编号：重复实现浏览器原生编号机制，且辅助技术仍只获得无序列表语义。

#### 影响面
