# C-013 完成提醒会话的处置语义：响应保持维持原视觉态，活动区→历史区迁移一律播放移动动画

日期: 2026-08-23

#### 上下文
东家反馈：点击完成提醒的活动卡后宿主立即清除 `completed`，卡片瞬间移入历史区，打断用户「查看后再决定如何处置」的上下文。由此确立响应保持行为（R-01-002/AC-05、R-01-010/AC-06/AC-07），其中两处存在认真候选方案需定夺：保持期间的视觉态，以及移动动画的适用范围。

#### 决策
- 响应保持期间维持「需要响应」标识与呈现样式不变，不降级为中性样式；用户一直停留在该会话则保持不解除。
- 移动动画适用于所有活动区→历史区的迁移，不限于响应保持解除这一种。

#### 被否方案及原因
- 保持期间降级为中性样式：削弱「该会话尚未处置完毕」的提示，且引入第三种视觉态增加辨识成本；东家选择简单无歧义的维持原状。
- 仅响应保持解除时播放移动动画：规则不统一——其它迁移（如选中态下运行结束落入历史区）同样瞬间消失，同样令人困惑。

#### 影响面
R-01-002 / 活动状态模型、R-01-010 / 活动状态模型、窗格渲染器
