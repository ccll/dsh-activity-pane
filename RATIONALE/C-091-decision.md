# C-091 兜底浮层贴靠宿主侧栏切换按钮成组

日期: 2026-10-10

#### 上下文
英雄页无标题行，兜底浮层显示在左上角（C-087 的回退条款）。移动壳层（dsh-web-mobile，iPhone 真机）下英雄页内容滚动穿过浮层下方，且浮层与宿主侧栏切换按钮分离，观感像误置（东家 16:17 截图）。实测（WebKit + iPhone UA）英雄页不存在可嵌入的布局行：宿主侧栏切换按钮是应用框架 grid 的直接子元素，自身就是自由浮动定位。

#### 决策
兜底浮层动态贴靠宿主侧栏切换按钮：每次落位同步实测该按钮矩形，浮层置于其右侧 8px 并与其垂直居中；按钮不可测时维持左上角兜底。会话页嵌入逻辑不变。

#### 被否方案及原因
- 强插宿主 grid 成兄弟项：需改写宿主网格模板轨道，宿主改版即碎，且改动宿主布局结构风险高，否。
- 英雄页隐藏开关：英雄页失去打开活动抽屉的唯一入口，功能损失，否。

#### 影响面
R-01-008 / 窗格渲染器（T-166）
