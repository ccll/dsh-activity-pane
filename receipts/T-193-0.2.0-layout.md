# T-193 DSH 0.2.0-rc.2 布局回执

## 运行

- 宿主: `dsh --version` = `0.2.0-rc.2`；e2e `bootE2e()` 启动隔离 `DSH_HOME`、mock LLM，并以 `link:` 安装当前分支插件（`.dsh-plugin/client.js`）。
- 浏览器: Playwright headless Chromium，1280×800，桌面端。
- 全局面板: 内置 Plugins 页。0.2.0 宿主不给中间列写 `data-global-panel`，插件走「中间列内无会话滚动区」回退判据。
- 探针时序: 会话视图 → Plugins → 立即 / 250ms / 750ms / 1500ms 采样 → 注入 `container-type: inline-size` 后 500ms 采样 → New Session 返回会话。

## 结果

| 阶段 | 中列方向 | 页根 | 窗格 | 观测 |
| --- | --- | --- | --- | --- |
| 会话视图 | row | 会话包装层（`display:contents`） | `display:flex`、280px | 滚动区 1、无标记 |
| 原生面板·立即 | row | `SECTION` 497px | `display:flex`、280px | 滚动区 0、无标记；同一帧内观察者尚未重排 |
| 原生面板·250ms | column | `SECTION` 1000px | `display:none`、0px | 回退判据已生效 |
| 原生面板·1500ms | column | `SECTION` 1000px | `display:none`、0px | 稳定，无回弹 |
| 原生面板 + containment | column | `SECTION` 1000px、`container-type: inline-size` | `display:none`、0px | #5 形态不再压窄 |
| 返回会话 | row | 会话包装层（`display:contents`） | `display:flex`、280px | 滚动区恢复 1 |

## E2E

- `node e2e/run.mjs desktop-layout` 在 0.2.0-rc.2 上通过（boot=3484ms、spec=6393ms、total=10306ms）。
- 该 spec 的原生面板用例走真实 0.2.0 回退分支并断言 column、窗格 `display:none`、页根 >90%、containment 已生效；marker 分支在 0.2.0 上以合成 `data-global-panel` 验证 0.2.2 判据，不依赖运行中宿主版本。

## 结论

- 0.2.0 无 `data-global-panel` 时，插件以会话滚动区缺失判定全局面板，约 250ms 内完成列布局复位与窗格收起，面板占满 1000px 中列；#5 的 inline-size containment 形态不再造成塌陷。
- 返回会话后行布局、窗格显隐与 280px 宽度恢复，无残留。
- 0.2.0 的不足 250ms 同帧瞬态（面板刚挂载、观察者尚未重排时窗格仍占 280px）与任务登记的残余风险一致；0.2.2 的标记判据没有该同帧延迟。

## 限制

- 使用内置 Plugins 页而非真实 dsh-market 入口；未发送消息，不覆盖流式/恢复/移动端路径，这些由 0.2.0 e2e 与 `pnpm verify` 覆盖。
- 本回执为 0.2.0-rc.2 的补充验证，不替代 [0.2.2 回执](T-193-0.2.2-layout.md)。
