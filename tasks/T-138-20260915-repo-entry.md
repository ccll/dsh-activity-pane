# T-138 标题行工具区新增 GitHub 仓库入口

状态: completed
关联: R-01-022/AC-01～AC-03 → 窗格渲染器
风险等级: standard

## 背景与目标

dsh-market 显示约 1.5k 下载但仓库 star 数仅 1：窗格是全部真实用户每天使用的唯一界面，却没有任何触点能看到 GitHub 仓库页，star 转化在源头断掉。东家拍板新增窗格内 GitHub 入口（R-01-022 原地新增）。目标：「活动会话」标题行右侧工具区（T-137 交付的 `.dap-tools`）新增纯图标 GitHub 仓库链接，新标签页打开 https://github.com/ccll/dsh-activity-pane，不干扰标题区折叠激活与既有工具区交互。

## 差距评估

- `src/client.mjs`：`.dap-tools` 内只有档位切换按钮；无仓库入口锚元素与图标工厂。
- `scripts/check.mjs`：bundle 契约无 R-01-022 断言。
- `e2e/specs/`：无仓库入口 spec。
- `scripts/acceptance.mjs`：无仓库入口人工步骤。

## 收敛方案

- AgentMap：PRD 新增 R-01-022（AC-01 常显链接、AC-02 激活隔离、AC-03 窄条隐藏）；DESIGN 需求追溯索引、窗格渲染器职责与产品契约同步；DOMAIN 无新概念、不改。
- AgentMap（审核修正，8b6ad58）：Standards 审核发现 PRD AC-01 写入精确 URL 违反「PRD 不出现接口形状/机制」，正文改为「打开项目的 GitHub 仓库页」，URL 由 DESIGN 产品契约承载——PRD AC-01 措辞原地收敛，AC-ID 与语义不变。
- `src/client.mjs`：`.dap-tools` 内新增 `<a class="dap-repo">`（`.dap-titlebar` 的兄弟节点 `.dap-tools` 的子元素；href 指向仓库页、`target="_blank"` + `rel="noreferrer noopener"`、可访问名称「打开 GitHub 仓库」），`createRepoIcon()` 复刻 MIT 许可的 GitHub Octicon `mark-github` 字形（14px 字形盒）；`.dap-repo` 与档位切换按钮同视觉语言（22px 圆形、不透明底色、hover/focus-visible 高亮），浅色主题并入既有 `.dap-top`/`.dap-density` 覆盖选择器；锚元素不进入标题区收起激活路径，随窗格骨架创建与移除。

## 测试计划

- `pnpm build:client && pnpm check`（bundle 契约锚定 R-01-022）。
- `pnpm test:e2e`（e2e/specs/repo-entry.mjs 锚定 R-01-022/AC-01～AC-03）。
- `python3 tools/agentmap_lint.py --report`；`pnpm verify` 全量门禁。
- 独立 `code-review` skill 双轴审核；存在 finding 时由同一 reviewer 复审至通过。
