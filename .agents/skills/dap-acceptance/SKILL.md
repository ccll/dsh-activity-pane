# dap-acceptance

本技能管人工验收的清单、真机口径与回执。自动化证明代码正确，人工验收证明功能正确。

- 分界：机器可判定进 spec；观感、视觉、真实设备、复杂编排留在 `scripts/acceptance.mjs`。
- 走查入口：`pnpm accept:manual`，或 `node tools/xtask.mjs accept`。
- 每条写可判定形式：做什么、看什么、什么算过；不写"确认体验良好"。
- 移动项按 WebKit + 移动 UA + 触屏 + 390×844 模拟壳层跑；真机触感、软键盘、发热必须真机。
- 桌面壳层通过不代表真机通过；两者 DOM 结构不同，分别取证。
- 未被覆盖的人工项登记进只减清单 manual-acceptance.txt，带原因与到期日；过期即失败。
- 需要真实宿主、真实数据或外部 registry 的项，写一次运行回执（run、环境、结论）。
- 回执写入即冻结；复跑或修正写新回执并引用旧的，不改旧回执。
- 回执在 `docs/compatibility.md` 对应行引用，读者从兼容矩阵能查到证据。
- 未实测不得声称已验证；PR 正文写"待人工验收"并列出未覆盖项。
- 验收日志用渲染状态码加截图回报，诊断码用后即撤、不进提交。
