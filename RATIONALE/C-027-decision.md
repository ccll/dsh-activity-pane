# C-027 工作区徽标色相弧收窄为十槽并避开红色警戒区（修订 C-026 的槽位布局）

日期: 2026-08-26

#### 上下文
C-026 的十二槽 30° 铺满整个色相环，必然覆盖红色区（约 330°–30° 环绕段）；东家要求避开红色这类警戒色，红色系在窗格中已被错误状态语义占用。
#### 决策
色相槽位从全环十二槽收窄为十槽色相弧：slot = hash % 10，基色 40° + slot×30°（槽位 40°–310°），叠加 ±10° 抖动后输出落在 [30°,320°]，红色区被整体排除；哈希无状态纯函数路线（C-026）不变。
#### 被否方案及原因
- 保持十二槽、命中红色区时重映射：分布不均且规则隐晦，不如直接收窄弧段直白。
- 连橙色一并排除（弧收窄为 60° 起）：东家仅要求避开红色，过度收窄无谓降低槽位数与区分度。
#### 影响面
R-01-003 / 活动状态模型、窗格渲染器
