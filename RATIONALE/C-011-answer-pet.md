# C-011 废弃沿自 answer-pet 的工具参数白名单摘要口径，文字以主会话窗口为唯一真相源

日期: 2026-08-22

#### 上下文
R-01-009/AC-04、AC-07 的工具参数白名单摘要（不展示完整命令）沿用自 answer-pet 的 trace 口径（见 C-005 上下文），并非东家显式要求；由此非选中态 fallback 摘要与选中态原生行文字语义不同，部分动作（todo_write、ask_user_question、cordis/未知工具、错误态、工作区内绝对路径）两态文字不一致，违反 R-01-012/AC-03。东家明确：可以且应当展示原始命令。

#### 决策
删除白名单约束：fallback 摘要镜像主会话窗口 `deriveSummary` 语义（分工具类型参数键、bash 含 command、无命中取首个字符串参数值、剥离工作区前缀、取首行），并复刻 todo/ask keyed 行的标题与状态摘要、错误态输出首行；PRD 两条 AC 同步改写。

#### 被否方案及原因
- 保留白名单、仅对齐标题与路径相对化：摘要两侧语义仍不同（cordis/未知工具/错误态继续漂移），且东家已否定该安全姿态。
- 非选中态也读主窗口 DOM 克隆文字：违背「非当前会话禁读主窗口 DOM」约束（跨会话串线风险），维持静态镜像方案。

#### 影响面
R-01-009、R-01-012 / 活动状态模型、窗格渲染器
