# C-029 工作区徽标色相改全弧均匀取色（djb2 雪崩终混后 30 + hash % 291），着色按单色系标签配色分主题校准（修订 C-027 的槽位布局）

日期: 2026-08-26

#### 上下文
T-070 落地后东家实测：可见的几个不同工作区徽标同显蓝色。查证根因有二：djb2 哈希低位分布聚集（slot = hash % 10 只取低位，长公共前缀路径挤进相邻槽位）；且十槽本身仅 10 个取值，生日悖论下少量工作区撞槽概率不低。同时东家提出新需求：前景与背景配色应符合美术选色经验、协调好看。
#### 决策
- 色相派生取消十槽量化与抖动：djb2 哈希先经雪崩终混（异或右移 + 乘法，高位熵折入低位），再全弧均匀取色 hue = 30 + hash % 291，输出 [30,320] 整数（291 个取值，撞色概率约 0.3%/对），避红弧口径（C-027）不变。
- 着色按单色系（monochromatic）标签配色经验分主题校准：深色主题文字取该色相高明度亮色（S 70 / L 68）、底色同色相 14% 透明铺底、描边 32%。
  - 浅色主题文字取低明度深色（S 72 / L 40）、底色 12%、描边 28%。
  - 前景与背景始终同色相、明度对比拉开。
#### 被否方案及原因
- 保留十槽、仅加雪崩混合修分布：修复聚集后撞槽概率仍约 10%/对，工作区稍多即再现同色，不满足「尽量分散」的意图。
- 保留文字混入 currentColor（88%）的原比例：高明度主题色被近白 currentColor 冲淡发灰，色相差异可辨性下降；提高基色占比（92%）更保色。
