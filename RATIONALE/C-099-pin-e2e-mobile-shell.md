# C-099 e2e 移动壳层钉版本：dsh-web-mobile 固定 3.2.0，上游漂移不追新

日期: 2026-10-22

#### 上下文
e2e 的移动壳层 spec（T-171 立的防误触断言：窗格开关命中盒不与任何可交互元素叠置）在 T-176 全量 verify 中确定性失败。根因诊断（钉版本对照实验）：上游 `dsh-web-mobile@3.2.1`（2026-10-20 21:55 发布，在 T-175 最后一次全量绿之后 7 小时）在移动壳层 header 新增 Chat/Trajectory 顶部标签页，其 bbox 与窗格开关 44×38 命中盒（R-01-008/AC-07 承诺 ≥44×38、AC-04 承诺标题行行首位——均不可让）垂直交叠 8px。e2e 每次在临时环境按名新装壳层（无版本 pin），registry 一发新版测试环境即随之漂移。本仓侧无干净解法：缩命中盒违约 AC-07、挪位置违约 AC-04。

#### 决策
e2e 壳层安装钉 `dsh-web-mobile@3.2.0`（钉最后全绿版本，e2e/boot.mjs 注释记原因）；产品面不适配 3.2.1，待上游修复后再评估追新（东家裁决，2026-10-22）。

#### 被否方案及原因
- 维持拉最新：全量 verify 持续红，掩盖真实回归信号，且破坏「验证绿 = 可提交」的门禁语义。
- 本仓适配 3.2.1 布局：须动 R-01-008/AC-07 或 AC-04 的 PRD 承诺（全链 + 东家再拍板），而叠置源头是上游把标签页放进会话 header 行带，责任方在壳层；用户 profile 尚停 3.0.6，实际使用未受影响，收益不成比例。
- 失败豁免/SKIP：把 T-171 防误触断言变成常态性跳过，防误触承诺失去回归保护。

#### 影响面
R-01-008 · 窗格开关；e2e 设施（boot.mjs 壳层安装行）
