# C-069 历史卡同时显示绝对日期时间与相对活动时间

日期: 2026-08-31

#### 上下文
历史分页取消了时间窗口后，卡片可能同时包含今天、跨天及跨年的会话；原有仅显示小时与分钟的「最近 HH:mm」无法判断会话具体日期，也不便快速比较新旧。

#### 决策
- 历史卡第五行显示本地时区的绝对日期与时分，并同时显示按分钟级别更新的相对活动时间。
- 当前年份的绝对时间省略年份以保持紧凑，跨年份时显示年份；相对时间按分钟、小时、天、周、月、年分级。
- 绝对日期时间是确定性依据，相对时间只作为快速扫读辅助；排序与活动时间来源仍使用 `activityAt`。

#### 被否方案及原因
- 只显示相对时间：跨日期或页面长时间打开后不易确认具体日期。
- 只显示绝对日期时间：可判断日期但不便快速感知会话距离当前有多久。
- 只在 hover tooltip 中提供另一种时间：移动端与键盘用户不易发现，关键信息不可见。

#### 影响面
R-01-013 · 窗格渲染器、活动状态模型
