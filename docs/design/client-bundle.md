# client bundle 生成与字节一致性

浏览器侧没有模块加载器：`src/core.mjs`、`src/navigation.mjs`、`src/client.mjs` 由构建脚本拼成单个 IIFE 形态的 bundle，发布物与门禁都以该产物的字节为准。

## 构建

- 脚本：`scripts/build-client.mjs`，导出 `build({ outPath })` 并支持直接执行。
- 默认输出：`.dsh-plugin/client.js`。
- 输入顺序：`src/core.mjs` → `src/navigation.mjs` → `src/client.mjs`。
- 转换：逐行剥掉行首 `export `，其余源码原样保留。
- 外壳：`window.__ModuleLoader__.load({ id: "dsh-activity-pane", factory: (require) => { ... } })`，内部构造 `module`/`exports` 并返回。
- 首行固定注释：`/* Generated by scripts/build-client.mjs; edit src/ instead. */`。
- 无压缩、无 sourcemap、无时间戳；相同输入恒得相同字节。
- 写盘：先写 `.tmp` 再原子 `rename`，避免 HTTP 读取或并发写入看到截断文件。
- 变体输出：性能 A/B 可传 `outPath` 到仓库外目录，产物不落工作树。

## 发布入口

| 入口 | 路径 | 形态 |
|---|---|---|
| 宿主插件 | `.dsh-plugin/index.mjs` | 静态转发 `apply`/`inject`/`name`，免构建 |
| 浏览器 bundle | `.dsh-plugin/client.js` | 构建产物 |
| 清单 | `package.json` | `main` 与 `exports` 指向上述两文件 |
| 挂载补丁 | `cordis.patch.yml` | 以插件 id 插入 bundle |

- `package.json` 的 `files` 含 `.dsh-plugin`、`src`、`scripts`、`cordis.patch.yml`、`README.md`、`LICENSE`。
- 宿主侧实现改动只发生在 `src/host.mjs`，入口文件保持静态。
- 插件不 patch 第三方插件，会话数据全部来自 DSH 原生服务。

## 字节一致性门禁

### staged 校验

- 脚本：`scripts/check-staged-client.mjs`。
- 输入取自 Git index：`scripts/build-client.mjs`、`src/core.mjs`、`src/navigation.mjs`、`src/client.mjs`、`.dsh-plugin/client.js`。
- 流程：把 staged 输入写入临时目录，执行 staged builder，再把生成的 bundle 与 staged bundle 按字节比较。
- 未暂存工作树不参与判定；校验器不改写 index。
- 失败提示：重新构建并重新暂存源码、构建脚本与 bundle。
- 缺任一 staged 输入直接报错，不降级为跳过。

### 工作树校验

- `scripts/check.mjs` 在断言后重建 bundle，再读取 `.dsh-plugin/client.js`。
- 断言 bundle 可被 `new Function` 解析，防止 CSS 模板破坏语法。
- 断言关键派生函数、交互绑定与样式选择器确实进入 bundle。
- 断言已废弃标识不存在，防止旧实现残留。
- 该脚本会写工作树 bundle，服务日常开发与 HMR。

### 开发重建

- `scripts/watch.mjs` 监视 `src/` 与 `scripts/build-client.mjs`。
- 变化后 80ms 去抖重建，只写默认输出路径。
- 配合壳层 HMR，浏览器热装插件，无需整页刷新。

## 一致性边界

- 源码与 bundle 字节必然不同：`export` 被剥离、外壳由 builder 注入。
- 唯一权威产物是 builder 输出；直接编辑 `.dsh-plugin/client.js` 会在门禁失败。
- 字节比较只覆盖已暂存内容；未暂存漂移由工作树校验发现。
- bundle 体积约 475KB，当前无独立字节预算门禁。
- `src/host.mjs` 不在 bundle 内：宿主侧由 cordis 加载 `.dsh-plugin/index.mjs` 后转引源码。

## 验证

- `scripts/check-staged-client.mjs`：staged 字节一致。
- `scripts/check.mjs`：工作树重建与产物契约。
- `scripts/build-client.mjs`：构建入口。
- `scripts/watch.mjs`：开发重建循环。
- `scripts/perf-ab.mjs`：以变体输出路径做性能对比，不污染工作树。
