# C-092 CONVENTIONS 新增「移动端真机验证」节

日期: 2026-10-10

#### 上下文
T-160～T-165 连续多轮「桌面验证通过、真机不成立」，根因为桌面壳层与移动壳层 DOM 结构不同而验证只在桌面壳层进行；东家要求记录教训避免重犯。

#### 决策
CONVENTIONS 新增「移动端真机验证」节：移动端 UI 改动须以 WebKit + 移动 UA + 触屏模拟移动壳层验证后再报完成；记录移动壳层已知 DOM 差异、锚点不耦合哈希类、诊断码取证纪律。

#### 被否方案及原因
- 只在 RATIONALE 记教训不进 CONVENTIONS：过程规范须在过程规范入口可查，散落决策层不可执行，否。

R-02-003 / 窗格渲染器（T-166）
