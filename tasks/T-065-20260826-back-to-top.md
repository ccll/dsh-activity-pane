# T-065 回到顶部悬浮按钮

状态: active
关联: R-01-018 / 窗格渲染器
风险等级: standard

## 背景与目标

东家需求：窗格滚动后在面板下方显示悬浮的「回到顶部」快捷按钮，一键回到窗格顶部。已升级为 R-01-018（AC-01 阈值显示 / AC-02 激活回顶、reduced-motion 直接定位 / AC-03 回到阈值内隐藏 / AC-04 移动端抽屉同适用、桌面窄条不显示）。

## 差距评估

- `.dap-scroll` 已有滚动监听（`bindPaneControls#onScroll`，R-01-004/AC-03 滚动条显隐），回到顶部按钮的显隐判定可挂入同一监听，无需新增 scroll 监听。
- 窗格骨架（`ensurePane` innerHTML）无按钮元素，需新增 `.dap-top` 胶囊按钮（默认 `hidden`）与配套 CSS。
- 激活回顶经 `scrollTo({ top: 0 })`；`prefersReducedMotion()` 已存在，命中时用 `auto`。

## 收敛方案

- 骨架：`.dap-scroll` 之后新增 `<button class="dap-top" hidden>↑ 回到顶部</button>`，随窗格创建/移除。
- CSS：`.dap-top` 绝对定位于窗格底部居中（`position:absolute; bottom:12px; left:50%; transform:translateX(-50%)`，z-index 高于滚动内容），胶囊样式与窗格主题协调；桌面折叠窄条态 `display:none`。
- JS：`bindPaneControls` 内 onScroll 同步 `topBtn.hidden = scroll.scrollTop <= TOP_THRESHOLD`（阈值常量 200px）；按钮 click 激活 `scroll.scrollTo({ top: 0, behavior: prefersReducedMotion() ? "auto" : "smooth" })`；unbind 清理 click 监听。
- 按钮为原生 `<button>`，键盘聚焦 + Enter/Space 激活由浏览器原生提供（click 同路径）。
