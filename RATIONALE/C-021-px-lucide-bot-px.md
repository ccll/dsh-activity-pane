# C-021 机器人图标改为小电视几何并回归 12px 盒（废弃 Lucide bot 原版几何与 13px 字形）

日期: 2026-08-26

#### 上下文
东家在实际渲染中发现两个机器人图标问题：与同行文字居中对齐后视觉偏下（原单折线天线占格顶、头部与底座墨量偏下，墨质心低于几何中心约 1px）；且比相邻 canonical 图标模糊。查证定位模糊根因：13px 字形盒在 14px 图标盒内产生 0.5px 半像素居中偏移，所有描边边缘落在物理像素之间被抗锯齿抹灰；且机器人是全图标表唯一 stroke 描边图标（渲染 1.18px、无实心核），canonical 图标均为 fill 实心剪影。原版几何为东家此前选定的 F 方案（Lucide bot 原样几何 + 13px 字形盒），选定当时未经实际渲染对齐与清晰度检验。
#### 决策
- 机器人图标以 Lucide bot 几何为底改造为小电视式：去双耳，头顶单折线天线改为两条 45° 外撇短斜线（`M10 8L7 5` / `M14 8L17 5`），机身圆角矩形与双眼竖线不变。
- 字形回归与其他时间线图标一致的 12px 盒（消除半像素偏移）；stroke-width 2 提为 2.2，12/22 缩放后渲染笔触 1.2px，与 canonical 填充轮廓（约 1px 实心环）视觉重量相当。
- viewBox 保持 `1 3 22 18` 保框：机身显示尺度与改造前一致，不因裁小框而变粗变大。
#### 被否方案及原因
- 保留原几何 + translateY(-1px) 墨迹补偿：现场实验后东家判定不治本——对齐观感依赖补偿值，且半像素模糊原样保留；该实验已回退，未入库。
- 裁 viewBox 到新笔墨边界盒（约 `3 4 18 17`）：显示尺度突增约 22%、描边渲染变粗至约 1.4px，与 canonical 图标视觉重量失衡。
- 14px 满盒字形：偏移为整数且更清晰，但比相邻图标明显大一圈，破坏同行尺度一致性（R-01-012/AC-11）。
- 重绘为 fill 实心几何：模糊主因已由 12px 盒消除，实心重绘的成本与风格漂移风险不抵收益。
