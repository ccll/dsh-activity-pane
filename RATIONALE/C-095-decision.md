# C-095 移动端活动开关与宿主控件尺度对齐

日期: 2026-10-10

#### 上下文
东家反馈移动端入口视觉偏小。
现行嵌入态高度为 26px。
计数文字字号为 10px。
宿主移动按钮基准为 38×38px。

#### 决策
选择与宿主移动控件对齐的固定入口尺度方案，同时保留现有落位与交互行为。

#### 被否方案及原因
- 只扩大透明命中区：不能修复视觉尺度偏小。
- 使用 44×44px：会把标题行撑高到宿主控件之上。
- 仅放大文字：徽标本体仍显得过窄。

#### 影响面
R-01-008 / 窗格渲染器（T-169）
