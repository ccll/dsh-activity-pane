# C-089 移动端「活动」开关落位改为视图导航行行尾，徽标单挂

日期: 2026-10-10

#### 上下文
T-161 紧凑形落地后东家仍不认可：真机截图显示胶囊处于兜底浮层位（左缘 ≈40pt、宽 ~147pt、内容仅 ~65pt，iOS 对 fixed 态按钮的尺寸行为，桌面 Chromium/WebKit 均复现不出），且面板图标被误读为「多了个边栏按钮」。东家明确指示：把胶囊嵌入其正下方的视图导航行（对话/轨迹/上下文 行）参与布局，而不是继续浮空。

#### 决策
落位目标由标题行改为视图导航行行尾并参与布局，放不下时回退兜底浮层；形态收敛为徽标单挂。

#### 被否方案及原因
- 维持标题行嵌入：宿主标题 crumb 只缩不涨，任何行内插入都把标题压到不可见下限，东家两轮反馈均不接受该观感。
- 保留面板图标：与宿主侧栏切换按钮同形，被东家误读为重复控件。
- 绝对定位铺在导航行右端空白处：不参与行的布局流，行内标签增长时会转为准遮挡，违背「参与布局」的诉求。

#### 影响面
R-01-008 / 窗格渲染器（T-162）
