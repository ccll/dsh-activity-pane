# T-123 dsh 0.1.5 适配：挂载重锚点与 remote/V3 日志数据层迁移

状态: completed
关联: R-01-001～R-01-020、R-02-002～R-02-004 → 全局宿主兼容性
风险等级: standard

## 背景与目标

- 背景: 本机 dsh 升级 0.1.5-rc.1 后插件整体失效。查证（宿主 bundle、运行时 DOM 侦察、WS 帧抓取、e2e 隔离环境复现）确认四类破坏：① web 外壳重构，`#root [data-slot="conversation"]` 槽座消失（conversation Slot 迁移为 keyed `main` slot）；② 客户端 `connection.api` RPC 门面移除（`connection` 仅余 `rpc/reconnect/start…`），`sessions.{models,history}` 每会话读取不复存在；③ 会话快照移除 `chat`/`partial`/`runningCalls`/`turnTimings`（Session 格式 V3），实时时间线与运行起始时刻失源；④ 会话列表条目 `title` 变 LLM 异步投影（null 时原生侧栏同样回退工作区名）。
- 定性: 技术迁移（东家确认）：PRD 不变，DESIGN 演进到目标态，行为不变由 e2e 契约证明；宿主行为语义变化（标题回退）由 spec 断言跟进。
- 目标: 插件在 dsh 0.1.5 上恢复全部既有能力：左侧贴边窗格挂载、活动/历史卡渲染、时间线与预览、模型上下文（含 T-122 的 effort 链）、回合统计。
- 非目标: 不改产品形态（不迁移到 `main` keyed 面板或 `shell.overlay` 浮层）；不为标题引入本地派生逻辑（跟随原生回退语义）；不升级 storage-domain 依赖版本（宿主自带 0.1.5-rc.2，插件声明 0.1.0-rc.6 的 API 兼容且 e2e 验证）。

## 差距评估

- client.mjs 挂载: `CONVERSATION_SELECTOR` 指向已消失的槽座（已验证改指 `#root [data-slot="main"]` 即恢复挂载，`conversationFlexItem` 的 display:contents 跳层逻辑与新结构兼容）。
- client.mjs 数据层: `inject` 缺 `remote`；`loadNativeDetails` 依赖 `connection.api.sessions.{models,history}` 全部失效；`livenessFromSnapshot` 依赖快照 `turnTimings` 失效；实时时间线（快照 `chat`）失效。
- host.mjs: `sessionQuery.listEvents` 形状未变（seq/type 字段仍为日志记录口径），e2e 验证回合统计。
- e2e: hero/composer 变 Lexical contenteditable + 占位文案加后缀（helpers/specs 已适配）；卡片标题断言需跟进新标题语义。
- DESIGN: 挂载契约（宿主依赖行）、轮内状态输入、宿主 DOM 观察、历史分页运行时四处描述旧宿主形态。

## 收敛方案

1. 挂载: `CONVERSATION_SELECTOR` 改指 `#root [data-slot="main"]`（keyed main slot 容器，外壳注册的稳定公共面）；注释与 DESIGN 同步。
2. 数据层: `inject` 增 `remote`（`@deepseek-ai/dsh-api-remotes`）；`loadNativeDetails` 改为：
   - 模型上下文: 主会话走目录链（目录 store 订阅 + 显式一次性 `load()`，0.1.5 目录 store 惰性加载，C-075 修订 C-024「只订阅不 load」）；子代理走会话日志 `request/header`（`config.{model, reasoningEffort}`）提取链（宿主以 agent-busy 拒绝子代理目录 RPC）；部署级目录经 `remote.session.modelCatalog()` 收获 `groups` → `catalogModelEntries`（主/子共享）。
   - 日志分页: `remote.session.page({address, throughSeq, beforeSeq, maxMessages})` → 归一 `{events, hasMore}` 喂既有 `pagedHistoryEvents`；主会话地址 `{kind:"session", sessionId}`，子代理地址 `{kind:"subagent", parentSessionId, childSessionId, mode}`。
   - 运行起始时刻: `livenessFromSnapshot` 改由宿主侧 busy 通道 `openTurnStart`（既有只读快照）提供。
   - 实时时间线: `session.subscribe` 推送驱动 `captureSessionLog` 就地读取 eventSource 窗口（快照引用变化才重算，无轮询），经既有 `foldedHistoryTimeline`/`messagePreviews` 就地更新 `detail.timeline`/`previews`；活动卡时间线以 eventSource 窗口派生为主源——transient `assistant/live-chunk` 按 `attemptId` 累积为 running live 行、非用户 source 的 `user/message` 按 provenance 投影为上下文注入/跨会话召回行、阻塞等待呈现下折叠前落定残留 running 行（settleIdle，`foldedHistoryTimeline` 新增参数）。
   - 等待行动: `inject` 增 `uiSession`，待确认/待审查/待回复改经 `uiSession.pendingInteractions` 快照回填行副本（0.1.5 sessions 行不再承载 `pendingInteraction`；interaction.kind 与既有 pendingInteraction 词汇一致：approval/plan-review/question），等待卡分类与呈现口径不变。
3. e2e 基建: hero/composer 定位器改 `data-placeholder` 前缀 + `textContent` 校验；会话页 composer 提取共享 `sessionComposer` helper；标题断言经全量验证无需改写（0.1.5 投影 title 与工作区名回退语义与既有断言兼容）；`long-list.mjs` 滚动隔离基线前等待宿主流式渲染的可滚动集合稳定（与窗格无关的宿主侧收敛不参与断言）；`auto-update.mjs` 控制台错误过滤宿主资源 404 噪声（断言对象保持插件报错与未捕获异常）；`boot.mjs` 预置 `ui-onboarding.welcomeNoticeVersion` 抑制宿主欢迎模态遮罩拦截指针。
4. DESIGN: 宿主依赖（挂载锚点）、轮内状态输入（V3 日志/投影/模型目录）、宿主 DOM 观察（seat=main 容器）、历史分页运行时（page RPC）四处演进到目标态。
